- **Навигация сверху** — логотип «Антифрод Центр Казахстан», ссылки: Главная, Проверка, Стадия, Услуги, Команда, Кейсы, Заявка

- **Hero-секция** — анимированные частицы на фоне, заголовок «Ваш центр взаимодействия», бейдж «Платформа координации»
- **Кнопки** — «Оставить заявку» (открывает форму), «Кейсы» (ссылка)
- **Статистика** — 184K+ дел, 87% без суда, 24ч реакция, 316 млрд ₸
- **Поиск** — ввод номера дела, ФИО или телефона → поиск по базе
- **Активные дела** — карточки с космическим дизайном (gradient border, glow при наведении)
- **Секция «Как мы работаем»** — 4 шага: Консультация → Анализ → Заявления → Возврат
- **CTA** — «Начните сейчас» с кнопкой «Оставить заявку»
- **WhatsApp кнопка** — зелёная иконка внизу справа
- **Нижняя навигация** (мобилка) — 7 кнопок с иконками

### Что делает клиент:
1. Нажимает «Оставить заявку» → открывается форма в модалке
2. Заполняет: ФИО, ИИН, телефон, сумму, платформу, детали
3. Нажимает «Отправить» → данные уходят в Telegram
4. Видит сообщение «Отправлено! Мы свяжемся с вами»
5. Или нажимает WhatsApp → переход в мессенджер

## 2. ПРОВЕРКА РЕКВИЗИТОВ (/check/)

### Что видит клиент:
- **Заголовок** — «Проверка реквизитов»
- **Поисковая строка** — вводит название платформы или организации
- **Кнопка «Проверить»**
- **Результат** — одна из трёх карточек:
  - 🚫 **«В ЧЁРНОМ СПИСКЕ»** — красный, показывает причину, ссылки на АРРФР
  - ✅ **«ЛИЦЕНЗИРОВАНА»** — зелёный, подтверждает легитимность
  - ⚠️ **«НЕ НАЙДЕНА»** — жёлтый, предупреждает о рисках
- **Детали** — сайт организации, статус в реестре АРРФР, причина (если есть)
- **Рекомендации** — что делать дальше
- **Кнопки** — «Оставить заявку», «Сайт организации»
- **Секция «Как работает проверка»** — 4 шага с иконками

### Что делает клиент:
1. Вводит название: «InvestPro Capital» или «CryptoGain KZ»
2. Нажимает «Проверить» → 1.5 секунды анимация загрузки
3. Видит результат: чёрный список / легитимна / не найдена

5. Нажимает «Оставить заявку» → переходит на страницу контактов

## ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Что работает «под капотом»:
- Все формы отправляют данные в Telegram Bot API (невидимо для клиента)
- Поиск по делам работает через localStorage + JSON
- Проверка реквизитов — встроенная база из 18 организаций
- Тест стадий — 5 вопросов, 4 стадии, математика баллов
- Анимации — IntersectionObserver + CSS transitions
- WhatsApp — прямая ссылка на мессенджер

### Данные клиента:
- Имя, ИИН, телефон, email
- Название платформы
- Сумма убытка
- Описание ситуации
- Все данные уходят в Telegram и НЕ сохраняются на сайте
